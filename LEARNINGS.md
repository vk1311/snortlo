# What the nightly run has learned

The nightly run ("All channels nightly") **reads this file at the start** of every run and **updates it at the end** (the Reflect step). It's how each run gets better than the last one instead of repeating mistakes.

## How to reflect (end of every run, 5 minutes max)
1. **What broke tonight and how you fixed it.** If the fix belongs in code or a doc, make the fix there (engine/, *.md) so it never happens again, then add a one-line rule of thumb below.
2. **What the numbers say.** Snortlo: experiments/REPORT.md (pick.py already favours winners). Podcasts and brand Shorts: compare view counts on the brand YouTube channels when available. Note any clear winner or loser with its sample size; don't call a winner on fewer than 3 samples.
3. **One small improvement for tomorrow.** Pick one: a sharper hook pattern, a better visuals search habit, a caption tweak, a new experiment arm in experiments/arms.json, retiring an arm with 10+ samples that keeps losing, or a speed-up in the engine. Do it, and log it in the night log.
4. **Sundays: the weekly review.** Rewrite "Rules of thumb" (merge, cut stale lines, stay under 30 lines), and put 1 or 2 bigger ideas in the report as **proposals for Vatsal** (don't do them).

## What the run may change by itself
- Bug fixes and speed-ups in engine/ (test before committing).
- Wording and clarity of the repo docs, and the writing guidance in STORY_FORMAT.md / CAPTIONS.md / PODCAST_FORMAT.md, when the numbers or a failure show something better.
- Experiment arms (add new arms freely; remove only after 10+ samples).
- Which photo searches, hooks, themes and title styles to use.

## Needs Vatsal's OK first (list as a proposal in the report, don't do it)
- Posting schedule, YouTube caps, which channels get what, new series or formats, stopping a series.
- Voices, the look of the videos, the AI note, honesty rules, anything about his brands' positioning.
- Anything that costs money or needs a new account or login.

- Kaggle can sit QUEUED 30+ min before RUNNING (Nov 24); that's not 'down'. Keep polling, and write/research everything else meanwhile.
- Kaggle token: Google Docs shows the underscore as "\_"; remove the backslash. Export KAGGLE_USERNAME in the same shell call that runs nightly.py. If setup.sh fails on a network reset, rerun it.
- The shell tool's DEFAULT timeout is 2 min: run voices, `nightly.py render` with a story, compile.py, podcasts and shrink.sh in the background with `setsid nohup ... < /dev/null & disown` (plain nohup died with its shell on Nov 20) and poll with `sleep` under 290 s (pass a longer timeout). If the voices process dies while Kaggle is RUNNING, don't push a new run: `python3 engine/kaggle_tts.py collect - /tmp/snortlo-voice` waits for that kernel and fills the cache, then rerun `nightly.py voices`. Never `pkill -f` a pattern matching your own command; kill by PID. To stop a setsid render, kill its whole process group (`kill -- -<PGID>`, from `ps -o pgid= -p <pid>`), or its ffmpeg keeps writing the same mp4 and corrupts the next render (Nov 26).
- Chatterbox (backup voice) needs the CPU-only torch reinstall and the float32 patches in voice_backend._ensure_chatterbox().
- ALWAYS read every `"ok"`, `layout_warnings` and the `done ... <seconds>` line in `nightly.py render`; a failed item still leaves a file behind (qc flags it "BROKEN"). Render memes in ONE render call.
- Halifax is UTC-4 from Nov 1 (DST ended); recheck the offset in March.
- Sunday compilation: paste media/compile-<date>.description.html as the Facebook content; never hand-type chapters. Housekeeping goes by the dates in schedule-log.md, not `find -mtime`.
- Ad-hoc whisper checks: faster_whisper can't decode files with this PyAV; gov.py render already refuses a cut whose caption words aren't in the audio, so trust that + the qc frame.
**Files and media**
- Every media file < 99 MB (Postiz pulls from raw.githubusercontent.com). Brand names the voice gets wrong go in voice_backend.SAY.
- A new YouTube channel must be phone-verified before any video over 15 min (Waypoint episodes can run to 15:30).
**Podcasts (and Waypoint, same pipeline)**
- Visual first: full-screen photos every ~7 s, cards, big captions; AI disclosure = one small corner note + description only.
- Length: 3,900-4,300 spoken words for 20+ min (3,724 = 19.6 min). Plan 6 segments.
- Photos: 'cheque book', 'postage stamps', 'coins', 'cardboard boxes', 'bank vault', 'government building' pull foreign text, faces or off-topic buildings; prefer 'calculator', 'ledger book', 'padlock'. Plain nouns for places and objects (no mood words, no people; 'reviews stars'/'gold trophy' pull NASA crews; 'nurse station', 'delivery truck', 'front desk' pull people, use 'stethoscope', 'cardboard boxes'). Commons first, Openverse second; ~30-45 s per search, start renders early.
- Before rendering a podcast/Waypoint JSON run `python3 engine/nightly.py check <json>` (also flags a host saying "I'm <name>" that isn't the on-screen host: Staffkin = Eric, Keegix = Nicole) (also shown as `visuals_warnings` in render output) and swap every flagged search; the list is RISKY_SEARCHES in engine/nightly.py (add to it after each photo review). Blocking alone isn't enough for a bad search: it refills from the same search (ep 5's 'coins' came back as 3 new foreign/logo coins), so swap the search word too.
- ALWAYS review photos (`nightly.py photos <episode json or timeline>` + engine/photos.png) and `nightly.py block` people (even hands), military/tragedy, politicians, logos, paintings with people, off-topic frames; re-render and review again.
**Long videos (podcasts and Waypoint explainers)**
- Re-hook every 60 to 90 s (tease, open question, surprising number; every tease pays off), and start each Short on a re-hook line. Rule in PODCAST_FORMAT.md (Vatsal, Nov 16) and waypoint/WAYPOINT_FORMAT.md. Not for sleep stories. Check it worked in experiments/channels.csv (avg_view_pct of episodes, was 7-11% on Nov 16).

- Sleep stories (Fridays): run `pick.py sleep` first, follow it, and log the upload with log_post.py (LONGFORM_FORMAT.md "Experiments", Vatsal Nov 16). Scored on views_7d; first 6 backfilled.

- Voiced memes ignore `hold` on spoken beats; lengthen them with `pause` (first-day-back went 8.6 s -> 14.0 s).
